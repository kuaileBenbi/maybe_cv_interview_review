# 第二讲 三维空间刚体运动

| 题号 | 答案 | 解析 |
|------|------|------|
| 2.1 | **C** | 刚体位姿 = 3个旋转自由度 + 3个平移自由度 = 6个自由度 |
| 2.2 | **B** | 旋转矩阵属于特殊正交群 SO(3) = {R∈ℝ³ˣ³ \| RᵀR=I, det(R)=1} |
| 2.3 | **A** | 正交约束：RᵀR=I（正交性）和 det(R)=1（保方向性，排除反射） |
| 2.4 | **B** | 旋转向量 = 旋转轴方向n（单位向量）× 旋转角度θ，即 θn |
| 2.5 | **B** | n^ 表示向量n的反对称矩阵（skew-symmetric matrix），用于叉积的矩阵形式 |
| 2.6 | **B** | 万向锁是欧拉角的固有缺陷，在pitch=±90°时第一次和第三次旋转退化到同一轴 |
| 2.7 | **B** | ZYX欧拉角中，Pitch（绕Y轴）为±90°时出现万向锁 |
| 2.8 | **A** | 单位四元数 [cos(θ/2), n·sin(θ/2)] 表示绕轴n旋转θ角。注意角度是θ不是θ/2 |
| 2.9 | **B** | 用四元数旋转点p的公式：p' = q ⊗ p ⊗ q*（q*为共轭），这是标准的四元数旋转公式 |
| 2.10 | **B** | 齐次坐标将旋转和平移统一为4×4矩阵乘法，避免了加法与乘法混合 |
| 2.11 | **B** | ⎡R t; 0ᵀ 1⎦ 中左上3×3=R（旋转），右上3×1=t（平移） |
| 2.12 | **C** | 单位四元数没有奇异性问题。欧拉角有万向锁，旋转向量在θ=2π时退化 |
| 2.13 | **C** | Sim(3) = ⎡sR t; 0ᵀ 1⎦，比SE(3)多一个尺度因子s，用于单目SLAM的尺度优化 |

# 第三讲 李群与李代数

| 题号 | 答案 | 解析 |
|------|------|------|
| 3.1 | **A** | 群的四个性质：封闭性、结合律、单位元、逆元。交换律不是群必须满足的 |
| 3.2 | **B** | so(3)的元素是三维向量φ，其反对称矩阵φ^ ∈ ℝ³ˣ³ |
| 3.3 | **B** | exp(φ^) 展开后正好就是罗德里格斯公式，两者等价 |
| 3.4 | **B** | ξ = [ρ, φ]ᵀ，ρ是平移部分（3维），φ是旋转部分的李代数（3维） |
| 3.5 | **B** | 旋转矩阵R有正交约束 RᵀR=I，直接做加法更新会违反约束。李代数φ∈ℝ³无约束，更新后通过exp映射回SO(3) |
| 3.6 | **B** | 扰动模型推导：∂(exp(δφ^)Rp)/∂δφ = -(Rp)^，即旋转后点向量的反对称矩阵取负 |
| 3.7 | **B** | SE(3)指数映射 exp(ξ^) = ⎡exp(φ^) Jρ; 0ᵀ 1⎦，平移部分多了J矩阵 |
| 3.8 | **B** | BCH公式描述两个李代数元素指数映射的乘积：exp(φ₁^)exp(φ₂^) = exp((φ₁+φ₂+½[φ₁,φ₂]+...)^)，用于理解增量更新的组合 |
| 3.9 | **B** | SE(3)扰动模型雅可比：∂(Tp)/∂δφ = -(Rp+t)^，变换后点的反对称矩阵取负 |
| 3.10 | **B** | log()：李群→李代数。exp()：李代数→李群 |

# 第五讲 非线性优化

| 题号 | 答案 | 解析 |
|------|------|------|
| 5.1 | **B** | 高斯噪声下，最大似然 = 最小化负对数似然 = 最小二乘 |
| 5.2 | **B** | 梯度下降：x_{k+1} = x_k - α·∇f，α为步长 |
| 5.3 | **B** | 牛顿法利用Hessian矩阵（二阶导数）构建二次近似，收敛更快 |
| 5.4 | **B** | 高斯-牛顿法对残差函数f(x)做一阶展开：f(x+Δx) ≈ f(x) + JΔx |
| 5.5 | **A** | 高斯-牛顿正规方程：JᵀJ·Δx = -Jᵀf。C是LM方法（加了μI），D是牛顿法 |
| 5.6 | **B** | LM引入阻尼因子μ，(JᵀJ + μI)保证正定可逆 |
| 5.7 | **B** | μ大时 JᵀJ + μI ≈ μI，退化为梯度下降（小步长安全更新） |
| 5.8 | **B** | ρ大→近似好→减小μ→更信任二次近似→接近高斯-牛顿（更快收敛） |
| 5.9 | **B** | 鲁棒核函数将大残差的增长从二次降为线性，降低外点的影响 |
| 5.10 | **B** | Huber核：\|e\|≤δ时二次增长，\|e\|>δ时线性增长（不再是二次） |
| 5.11 | **B** | g2o中顶点=待优化变量（位姿、路标），边=约束（重投影误差等） |
| 5.12 | **B** | LossFunction即鲁棒核函数（如HuberLoss），降低外点对优化的影响 |
