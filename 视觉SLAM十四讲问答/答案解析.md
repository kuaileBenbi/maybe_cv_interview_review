# 视觉SLAM十四讲（第2版）答案解析

---

# 第一讲 前言与概述

**A1.1**
SLAM全称 Simultaneous Localization And Mapping（同时定位与建图）。核心问题：机器人在未知环境中运动时，需要同时估计自身的位姿（定位）并构建环境地图（建图），两者相互依赖，无法独立求解。

**A1.2**
- **定位**：在已知地图的情况下，根据传感器观测估计机器人当前位姿。
- **建图**：在已知位姿的情况下，根据传感器观测构建环境地图。
- **相互依赖**：定位需要地图作为参考，建图需要准确的位姿信息。这是典型的"鸡与蛋"问题，需要同时求解。

**A1.3**
| 传感器 | 优点 | 缺点 |
|--------|------|------|
| 单目相机 | 成本低、体积小、信息丰富 | 无法直接获得深度，存在尺度不确定性 |
| 双目相机 | 可通过视差计算深度，无需额外设备 | 基线限制了有效深度范围，计算量大 |
| RGB-D相机 | 直接获取深度信息，适合室内 | 有效距离短（通常<10m），室外受日光干扰 |

**A1.4**
里程计仅利用相邻帧的信息估计相对运动，只做"递推"不维护全局一致性。SLAM在此基础上增加了后端优化和回环检测，能消除累积漂移。里程计可看作SLAM的前端模块。

**A1.5**
经典框架包含四个模块：
1. **传感器数据** → 获取图像/深度
2. **前端（视觉里程计）** → 从图像中估计相邻帧的运动（特征提取、匹配、运动估计）
3. **后端（优化）** → 对前端输出的位姿和路标进行全局优化，处理累积误差
4. **回环检测** → 判断机器人是否回到之前经过的位置
5. **建图** → 根据估计的轨迹构建地图

数据流：传感器 → 前端 → 后端 ← 回环检测 → 建图

**A1.6**
- **前端**：负责实时的短程数据处理，计算相邻帧之间的运动，要求速度快。相当于"快速但可能不准确的估计"。
- **后端**：接收前端的输出，进行长时间跨度的全局优化，可以较慢运行。负责保证全局一致性。
- 分工原因：实时性与全局一致性的需求不同，分离后可以各自优化。

**A1.7**
视觉里程计只做相邻帧的运动估计并串联，长期运行会产生不可逆的累积漂移。完整SLAM系统通过回环检测发现回到旧位置，再通过后端优化消除漂移，实现全局一致性。

**A1.8**
回环检测的意义在于发现"回环"（机器人回到之前的位置），提供跨时间的约束信息。没有回环检测，漂移误差会持续累积，无法修正，地图会出现断裂或重影。

**A1.9**
SLAM可建模为**状态估计问题**：
- **状态变量**：x = {x₁, x₂, ..., xₙ, m₁, m₂, ..., mₘ}，包含所有时刻的位姿xᵢ和所有路标点mⱼ
- **运动方程**：xₖ = f(xₖ₋₁, uₖ) + wₖ（uₖ为控制输入，wₖ为运动噪声）
- **观测方程**：zₖ,ⱼ = h(xₖ, mⱼ) + vₖ,ⱼ（vₖ,ⱼ为观测噪声）
- 目标：给定所有观测z和控制输入u，估计状态x的后验分布 P(x|z, u)

**A1.10**
- **运动方程** xₖ = f(xₖ₋₁, uₖ) + wₖ：描述从k-1时刻到k时刻的状态如何转移。xₖ₋₁为上一时刻位姿，uₖ为传感器读数（如IMU、轮速计），wₖ为过程噪声。
- **观测方程** zₖ,ⱼ = h(xₖ, mⱼ) + vₖ,ⱼ：描述在位姿xₖ处观测到路标mⱼ时得到的测量值zₖ,ⱼ。h为观测模型（如投影模型），vₖ,ⱼ为观测噪声。

**A1.11**
SLAM本质上是一个**状态估计问题**。在概率框架下，要求解的是状态的后验分布：
P(x|z, u) ∝ P(z|x) · P(x|u)
其中x是所有待估计状态，z是所有观测。在线性高斯假设下可用卡尔曼滤波求解；非线性情况下需用扩展卡尔曼滤波（EKF）或非线性优化方法。

**A1.12**
重要里程碑：
- 1986年：Smith等提出随机地图概念，标志SLAM问题正式提出
- 1990s：EKF-SLAM成为主流方法
- 2002年：Lu & Milios提出图优化框架
- 2006年：Davison实现实时单目SLAM（MonoSLAM）
- 2008年：Klein & Murray提出PTAM，分离前端与后端
- 2012年：Mur-Artal提出ORB-SLAM
- 2014年：Engel提出LSD-SLAM（直接法）
- 2016年：ORB-SLAM2支持单目/双目/RGB-D
- 2017年：VINS-Mono（视觉惯性融合）

**A1.13**
| 方法 | 基本思想 | 优点 | 缺点 |
|------|----------|------|------|
| 滤波器方法 | 维护当前状态的均值和协方差，每步更新 | 实时性好，计算量与当前状态相关 | 线性化误差累积，状态维度受限 |
| 图优化方法 | 将所有状态作为节点，约束作为边，构建图后全局优化 | 可以回溯修正，精度高 | 随状态增多计算量增大 |

**A1.14**
- **ORB-SLAM**：基于ORB特征，支持单目/双目/RGB-D，完整的SLAM系统（前端+后端+回环）
- **LSD-SLAM**：直接法，构建半稠密地图，不需要特征提取
- **PTAM**：首个分离追踪与地图构建的实时单目系统，引入关键帧机制
- **DSO**：直接稀疏里程计，光度标定，精度高

**A1.15**
- **特征点法**：提取图像特征（如ORB/SIFT），匹配特征点后利用几何约束估计运动。提取的是离散特征，丢失了大部分图像信息。
- **直接法**：直接利用像素灰度信息，通过最小化光度误差估计运动。可以使用所有像素或部分像素，不需要显式提取和匹配特征。

# 第二讲 三维空间刚体运动

**A2.1**
刚体运动是指物体在运动过程中形状和大小不变的变换。描述三维刚体位姿需要6个自由度：
- 3个旋转自由度（roll, pitch, yaw）— 姿态
- 3个平移自由度（x, y, z）— 位置

**A2.2**
旋转矩阵R是一个3×3正交矩阵，属于特殊正交群SO(3)。

正交约束条件：RᵀR = I（即R的转置等于R的逆），且 det(R) = 1。

物理含义：旋转矩阵的每一列（和每一行）都是单位向量且互相正交，保证了旋转不改变向量的长度和向量间的夹角。

**A2.3**
SO(3) = {R ∈ ℝ³ˣ³ | RᵀR = I, det(R) = 1}

性质：
- 行列式 det(R) = 1（旋转不改变体积，排除了反射）
- 逆矩阵 R⁻¹ = Rᵀ（正交性）
- 旋转矩阵的乘积仍是旋转矩阵（封闭性）

**A2.4**
由RᵀR = I：对任意向量v，||Rv||² = (Rv)ᵀ(Rv) = vᵀRᵀRv = vᵀv = ||v||²
所以旋转不改变向量长度。

对RᵀR = I两边取行列式：
det(RᵀR) = det(I) → det(Rᵀ)·det(R) = 1 → [det(R)]² = 1 → det(R) = ±1

因为SO(3)要求连续地从单位矩阵变换而来（单位矩阵的行列式为1），连续变换不会跳到-1，所以 det(R) = 1。

**A2.5**
旋转向量用一个三维向量 **θn** 表示旋转：方向n为单位向量，表示旋转轴；模长θ表示旋转角度。它将旋转矩阵的9个量压缩到3个量，正好对应旋转的3个自由度。

**A2.6**
罗德里格斯公式：
R = cosθ·I + (1-cosθ)·nnᵀ + sinθ·n^

其中：
- θ为旋转角度
- n为旋转轴方向的单位向量
- n^为n的反对称矩阵

**A2.7**
旋转矩阵9个量但只有3个自由度（正交约束和行列式约束减少了6个自由度）。旋转向量直接用3个量（θ, nₓ, nᵧ, n_z，其中||n||=1所以实际也是3个自由度）。

优点：紧凑（最小参数化）、没有冗余约束
缺点：旋转轴n的模长隐含了角度θ，有奇异性（θ=2π时与θ=0等价）

**A2.8**
推导思路：设旋转向量为a = θn，要对向量v进行旋转得到v' = Rv。

将v分解为平行于n和垂直于n的分量：
- v_∥ = (v·n)n = nnᵀv（平行分量，旋转不变）
- v_⊥ = v - v_∥ = (I - nnᵀ)v（垂直分量，在旋转平面内旋转θ角）

垂直分量的旋转：v_⊥' = cosθ·v_⊥ + sinθ·(n × v)

合并：v' = v_∥ + v_⊥' = nnᵀv + cosθ(I - nnᵀ)v + sinθ(n^)v
= [cosθ·I + (1-cosθ)·nnᵀ + sinθ·n^] v

即 R = cosθ·I + (1-cosθ)·nnᵀ + sinθ·n^

**A2.9**
欧拉角用三次绕坐标轴的旋转来描述姿态。ZYX顺序（即RPY）：
- Roll (φ)：绕X轴旋转
- Pitch (θ)：绕Y轴旋转
- Yaw (ψ)：绕Z轴旋转
旋转矩阵：R = R_z(ψ)·R_y(θ)·R_x(φ)

**A2.10**
万向锁（Gimbal Lock）：当pitch角为±90°时，第一次和第三次旋转会退化到同一个旋转轴，丢失一个自由度。

例如当pitch = 90°时，roll和yaw的效果完全相同，无法区分绕竖直轴的旋转和绕前后轴的旋转，导致系统只有2个有效旋转自由度。

**A2.11**
在SLAM中通常使用旋转矩阵或四元数表示旋转（无奇异性），但欧拉角直观易理解，用于人机交互和调试时显示姿态，因此需要了解它。

**A2.12**
四元数 q = q₀ + q₁i + q₂j + q₃k = [s, v]，其中s=q₀为实部，v=(q₁,q₂,q₃)为虚部向量。

也可写成 q = [w, x, y, z]ᵀ，其中w为实部，(x,y,z)为虚部。

**A2.13**
单位四元数约束：||q|| = w² + x² + y² + z² = 1

单位四元数q = [cos(θ/2), n_x·sin(θ/2), n_y·sin(θ/2), n_z·sin(θ/2)]对应绕轴n旋转θ角的旋转。

**A2.14**
q = [q₀, q₁, q₂, q₃] 到旋转矩阵R的转换：

R = ⎡1-2(q₂²+q₃²)  2(q₁q₂-q₀q₃)  2(q₁q₃+q₀q₂)⎤
    ⎢2(q₁q₂+q₀q₃)  1-2(q₁²+q₃²)  2(q₂q₃-q₀q₁)⎥
    ⎣2(q₁q₃-q₀q₂)  2(q₂q₃+q₀q₁)  1-2(q₁²+q₂²)⎦

**A2.15**
用四元数旋转三维点p（表示为纯四元数p = [0, x, y, z]）：

p' = q ⊗ p ⊗ q⁻¹ = q ⊗ p ⊗ q*

其中q*为q的共轭（实部不变、虚部取反），⊗为四元数乘法。

展开后等价于矩阵形式：p' = R·p

**A2.16**
四元数的优势：
- 只有4个参数（vs 旋转矩阵9个），且约束简单（||q||=1）
- 无万向锁奇异性（vs 欧拉角）
- 插值方便（球面线性插值SLERP）
- 计算高效，组合旋转只需四元数乘法
- 在SLAM中广泛使用，结合李代数可以进行优化

**A2.17**
SE(3) = {T = [R t; 0ᵀ 1] | R ∈ SO(3), t ∈ ℝ³}

特殊欧氏群SE(3)包含旋转R和平移t，完整描述了三维刚体变换（6个自由度）。

**A2.18**
齐次坐标将三维点(x,y,z)表示为(x,y,z,1)，将三维向量表示为(x,y,z,0)。

好处：旋转和平移可以统一写成4×4矩阵乘法：
T·[x,y,z,1]ᵀ = [R·p + t, 1]ᵀ

避免了仿射变换中"加法"与"乘法"混合的情况，使变换的组合等于矩阵连乘。

**A2.19**
齐次变换矩阵：
T = ⎡R  t⎤
    ⎣0ᵀ 1⎦

- 左上3×3分块R：旋转矩阵
- 右上3×1分块t：平移向量
- 左下1×3分块0ᵀ：零向量
- 右下1×1分块1：常数1

T将点p从坐标系A变换到坐标系B：p_B = T_BA · p_A

**A2.20**
- SE(3)：只有旋转和平移，保持距离不变（等距变换）
- Sim(3)：在SE(3)基础上增加了尺度因子s，变换矩阵为 ⎡sR  t; 0ᵀ 1⎦
- 场景：单目SLAM中存在尺度不确定性，用Sim(3)可以同时优化尺度和位姿

# 第三讲 李群与李代数

**A3.1**
群是集合G配上运算∘，满足：
1. **封闭性**：∀a,b ∈ G，a∘b ∈ G
2. **结合律**：(a∘b)∘c = a∘(b∘c)
3. **单位元**：∃e ∈ G，使得 e∘a = a∘e = a
4. **逆元**：∀a ∈ G，∃a⁻¹ 使得 a∘a⁻¹ = e

**A3.2**
- **李群**：具有连续（光滑）性质的群。SO(3)和SE(3)都是李群。
- **李代数**：李群在单位元处的切空间，描述了李群的局部结构。每个李群都有对应的李代数。
- **关系**：李代数通过指数映射（Exponential Map）与李群建立一一对应（在局部范围内），李群通过对数映射回到李代数。

**A3.3**
so(3)是SO(3)的李代数，定义为：
so(3) = {φ ∈ ℝ³ | φ^ ∈ ℝ³ˣ³}

其中φ^是φ的反对称矩阵。so(3)的基底为：
e₁^ = ⎡0 0 0; 0 0 -1; 0 1 0⎤, e₂^ = ⎡0 0 1; 0 0 0; -1 0 0⎤, e₃^ = ⎡0 -1 0; 1 0 0; 0 0 0⎤

任意元素可写成 φ^ = φ₁e₁^ + φ₂e₂^ + φ₃e₃^，其中φ = (φ₁, φ₂, φ₃)。

**A3.4**
se(3)的元素为ξ = [ρ, φ]ᵀ，其中ρ是平移部分（3维），φ是旋转部分（3维，对应so(3)）。

ξ^ = ⎡φ^  ρ; 0ᵀ  0⎤ 是4×4矩阵，其中φ^是φ的反对称矩阵。

**A3.5**
指数映射：exp(φ^) = Σ(φ^)ᵏ/k! (k=0到∞)

对于so(3)→SO(3)，展开后恰好就是罗德里格斯公式：
exp(φ^) = cos||φ||·I + (1-cos||φ||)·(nnᵀ) + sin||φ||·n^

其中 n = φ/||φ||。

**A3.6**
设φ = θn（θ = ||φ||，n为单位向量），则：
exp(φ^) = I + φ^ + φ^²/2! + φ^³/3! + ...

利用反对称矩阵性质 n^³ = -n^，可对高阶项化简：
exp(φ^) = I + (sinθ)n^ + (1-cosθ)(n^)²

这正是罗德里格斯公式。因此so(3)的指数映射等价于罗德里格斯公式。

**A3.7**
SE(3)的指数映射：
exp(ξ^) = ⎡exp(φ^)  Jρ; 0ᵀ  1⎦

其中 J = (sinθ/θ)I + (1-sinθ/θ)(nnᵀ) + (1-cosθ/θ)n^

J是一个3×3矩阵，比SO(3)多了一个J因子作用于平移部分ρ。

**A3.8**
BCH公式描述两个李代数元素指数映射之积：
exp(φ₁^)·exp(φ₂^) = exp((φ₁ + φ₂ + ½[φ₁,φ₂] + ...) ^)

在SLAM中，当我们对位姿进行小量更新时（R·exp(Δφ^)），需要用BCH公式理解两次更新的组合效果。当增量Δφ很小时，高阶项可忽略，近似为加法。

**A3.9**
旋转矩阵R有正交约束 RᵀR = I 和 det(R) = 1，这些约束使得：
1. 不能直接对R做加法更新（更新后可能不再满足正交约束）
2. R的导数不封闭在SO(3)中
3. 需要在无约束的李代数空间φ上进行优化更新，再通过指数映射回到SO(3)

**A3.10**
李代数求导模型：
设R(t) = exp(φ(t)^)，则旋转后的点 p' = R·p

对φ求导：
∂(Rp)/∂φ = lim[exp((φ+Δφ)^)·exp(-φ^)·p - p] / Δφ

利用BCH公式的一阶近似和exp(φ^)的性质，最终得到：
∂(Rp)/∂φ = -(Rp)^ = -(R·p)^

即旋转点对李代数的雅可比为 -(Rp)^（反对称矩阵形式）。

**A3.11**
扰动模型（左扰动）：
对R施加一个左扰动 ΔR = exp(δφ^)，求：
∂(R·p)/∂δφ|_{δφ=0} = lim [exp(δφ^)·R·p - R·p] / δφ

一阶泰勒展开：exp(δφ^) ≈ I + δφ^
= (I + δφ^)·R·p - R·p = δφ^·R·p = -(R·p)^·δφ

所以：∂(R·p)/∂δφ = -(R·p)^

区别：李代数求导模型对φ本身求导（推导较复杂），扰动模型对增量δφ求导（推导简洁，实际更常用）。

**A3.12**
SE(3)扰动模型：
T的扰动 ΔT = exp(δξ^)，其中δξ = [δρ, δφ]ᵀ

对变换后的点 T·p（齐次坐标）求导：
∂(T·p)/∂δξ = ⎡-(Rp+t)^  I; 0ᵀ  0ᵀ⎤

其中前3列对应旋转扰动δφ，后3列对应平移扰动δρ。

在优化中，位姿增量δξ = [δρ, δφ]通过求解线性方程得到，然后用 T ← exp(δξ^)·T 更新位姿。

**A3.13**
原因：
1. 旋转矩阵有正交约束（RᵀR=I），直接更新容易违反约束
2. 李代数φ ∈ ℝ³是无约束空间，可以做加法更新：φ ← φ + Δφ
3. 更新后通过指数映射回到SO(3)：R ← exp(φ^)
4. 李代数的维度等于旋转的自由度（3维），是最小参数化

**A3.14**
Sophus库操作：
- `SO3 R(mat3x3)` 或 `SO3::exp(Vec3)` 创建旋转
- `SO3::log()` 李群→李代数
- `SO3::exp(Vec3)` 李代数→李群
- `SE3 T(mat4x4)` 或 `SE3::exp(Vec6)` 创建变换
- `SE3::log()` 李群→李代数

**A3.15**
在BA中，相机位姿用SE(3)表示，优化时：
1. 定义代价函数 eᵢ = uᵢ - π(Tᵢ·pⱼ)（重投影误差）
2. 计算e对位姿李代数δξ的雅可比：∂e/∂δξ
3. 通过高斯-牛顿或LM求解增量δξ
4. 更新位姿：Tᵢ ← exp(δξ^)·Tᵢ
5. 迭代直到收敛

# 第四讲 相机模型

**A4.1**
针孔相机成像：三维点P经过光心O投影到像平面上的点p'。光心到像平面的距离为焦距f。像平面上的投影点p'与物理点P的关系：p' = f·P/Z（Z为深度）。

关键概念：
- **焦距f**：光心到像平面的距离
- **光心O**：相机的光学中心
- **像平面**：距离光心f处，成像的平面

**A4.2**
完整投影链：
1. 世界坐标 P_w → 相机坐标 P_c = R·P_w + t（外参变换）
2. 相机坐标 P_c = (X, Y, Z) → 归一化坐标 (X/Z, Y/Z)（透视除法）
3. 归一化坐标 → 像素坐标 u = fx·(X/Z) + cx, v = fy·(Y/Z) + cy（内参变换）

**A4.3**
内参矩阵K：
K = ⎡fx  0  cx⎤
    ⎢0  fy  cy⎥
    ⎣0   0   1⎦

- fx, fy：x和y方向的焦距（像素单位），fx = F/dx（F为物理焦距，dx为像素大小）
- cx, cy：光心在像素坐标系中的坐标（主点）
- 通常fx ≈ fy（像素近似正方形时），简化为单焦距f

**A4.4**
外参包含旋转矩阵R和平移向量t，表示从世界坐标系到相机坐标系的变换：
P_c = [R|t]·P_w

R是3×3旋转矩阵，t是3×1平移向量，共6个自由度。

**A4.5**
完整公式链：
1. **世界→相机**：P_c = T_cw·P_w = R_cw·P_w + t_cw
2. **相机→归一化平面**：p_n = (X/Z, Y/Z, 1)ᵀ
3. **归一化→像素**：u = (1/Z)·K·P_c

综合：u = K·[R|t]·P_w / Z，或齐次形式 Z·u = K·[R|t]·P_w

**A4.6**
- **径向畸变**：由于透镜形状不规则导致，表现为离光心越远畸变越大。桶形畸变（k<0，广角镜头）和枕形畸变（k>0，长焦镜头）。
- **切向畸变**：由于透镜安装不平行（透镜平面与成像平面不平行）导致。

**A4.7**
径向畸变模型：
x_distorted = x(1 + k₁r² + k₂r⁴ + k₃r⁶)
y_distorted = y(1 + k₁r² + k₂r⁴ + k₃r⁶)

其中 r² = x² + y²，(x,y)是归一化平面坐标。
- k₁, k₂, k₃：径向畸变系数，通常k₃很小可忽略
- k₁<0：桶形畸变；k₁>0：枕形畸变

**A4.8**
切向畸变模型：
x_distorted = x + 2p₁xy + p₂(r² + 2x²)
y_distorted = y + p₁(r² + 2y²) + 2p₂xy

p₁, p₂是切向畸变系数，描述了透镜平面与成像平面之间的倾斜。

**A4.9**
去畸变流程：
1. 对每个输出像素(u_dist, v_dist)，计算归一化坐标(x_d, y_d)
2. 利用畸变模型反解出无畸变坐标(x, y)（迭代或近似）
3. 在无畸变图像中插值获取像素值
4. 赋给输出图像

标定中估计k₁,k₂,k₃,p₁,p₂参数（通常用张正友标定法），使用时通过这些参数做去畸变。

**A4.10**
双目相机通过两个水平放置的相机，利用三角原理测量深度。两个相机光心之间的距离B为基线，同一三维点在两个图像中的投影位置不同，水平方向的差值为视差d。视差越大，深度越小。

**A4.11**
设左相机观测到像素ul，右相机观测到像素ur，视差 d = ul - ur。

由相似三角形：
z/f = B/d → z = f·B/d

- z：深度
- f：焦距（像素单位）
- B：基线长度
- d：视差

视差d越大，深度z越小（近处物体视差大）。

**A4.12**
挑战：
1. **视差计算困难**：需要逐像素匹配，在弱纹理/重复纹理区域容易出错
2. **计算量大**：稠密匹配需要在每条极线上搜索
3. **遮挡问题**：部分区域在一个相机中不可见
4. **深度范围有限**：z = fB/d，当d很小时（远处物体），深度估计误差大

**A4.13**
- **ToF（Time of Flight）**：发射调制的红外光脉冲，测量光往返时间来计算距离。如Kinect V2。
- **结构光**：投射已知的红外图案（如散斑），通过图案变形计算深度。如Kinect V1、RealSense。

**A4.14**
局限：
- 有效距离短（通常5-10m以内），远距离精度迅速下降
- 室外受太阳红外光干扰严重
- 对高反射/透明物体深度测量不准
- 分辨率和帧率受限

**A4.15**
灰度图像：单通道，每个像素用0-255表示亮度。彩色图像三个通道：R（红色）、G（绿色）、B（蓝色），每个通道0-255，共可表示约1677万种颜色。

**A4.16**
图像在计算机中存储为二维矩阵（灰度）或三维矩阵（彩色）。注意坐标对应：
- 像素坐标 (u, v)：u对应列，v对应行
- 矩阵索引 image[row][col]：row = v, col = u
- 即 image[v][u] 对应像素 (u, v)

# 第五讲 非线性优化

**A5.1**
SLAM的状态估计可以表述为**最大后验估计（MAP）**：
P(x|z) ∝ P(z|x)·P(x)

取负对数，MAP等价于最小化：
-min log P(x|z) = min [-log P(z|x) - log P(x)]

**A5.2**
最小二乘问题标准形式：
minₓ ½ Σ ||fᵢ(x)||²_Σᵢ

其中fᵢ(x)是残差函数，Σᵢ是信息矩阵。

与MLE的关系：当噪声服从高斯分布时，最大似然估计等价于最小二乘。

**A5.3**
假设观测噪声 vₖ ~ N(0, Σ)，则：
P(zₖ|xₖ) ∝ exp(-½(zₖ - h(xₖ))ᵀΣ⁻¹(zₖ - h(xₖ)))

最大化似然 = 最小化 -log P = min ½ Σ (zₖ - h(xₖ))ᵀΣ⁻¹(zₖ - h(xₖ))
= min ½ Σ ||eₖ||²_Σ

这就是加权最小二乘问题。

**A5.4**
梯度下降法迭代公式：
x_{k+1} = x_k - α·∇f(x_k)

α为步长（学习率），∇f(x_k)为目标函数在x_k处的梯度。

**A5.5**
牛顿法不仅用梯度（一阶信息），还用Hessian矩阵H（二阶信息）：
x_{k+1} = x_k - H⁻¹·∇f(x_k)

牛顿法利用二次近似，收敛更快（二次收敛），但需要计算和存储Hessian矩阵（n×n），在高维问题中代价很大。

**A5.6**
| 方法 | 优点 | 缺点 |
|------|------|------|
| 梯度下降 | 简单，只需梯度 | 收敛慢（线性），可能锯齿形 |
| 牛顿法 | 收敛快（二次） | Hessian计算和存储代价大，可能非正定 |

SLAM中不用这两种方法的原因：梯度法太慢，牛顿法Hessian太大且可能不正定。通常用高斯-牛顿或LM方法。

**A5.7**
高斯-牛顿法推导：
目标：min ½ ||f(x)||² = min ½ Σ fᵢ(x)²

将f(x)在x附近一阶展开：f(x+Δx) ≈ f(x) + J·Δx

代入目标：min ½ ||f(x) + J·Δx||² = min ½ [fᵀf + 2fᵀJΔx + ΔxᵀJᵀJΔx]

对Δx求导并令其为0：JᵀJ·Δx = -Jᵀf(x)

令 H = JᵀJ, g = -Jᵀf(x)，则 H·Δx = g

求解得 Δx = H⁻¹·g = (JᵀJ)⁻¹·(-Jᵀf)

**A5.8**
H = JᵀJ 是Hessian的近似（省去了二阶项），在SLAM的BA问题中是大规模稀疏矩阵。

问题：
1. H可能奇异（不可逆），导致无法求解
2. H可能不正定，导致Δx不是下降方向
3. 这时需要用LM方法引入阻尼因子

**A5.9**
高斯-牛顿法迭代步骤：
1. 计算雅可比矩阵J和残差f(x)
2. 构建正规方程 H·Δx = g，其中 H=JᵀJ, g=-Jᵀf
3. 求解Δx
4. 更新 x ← x + Δx
5. 判断收敛：||Δx|| < ε 或残差变化很小

**A5.10**
LM方法在高斯-牛顿基础上增加阻尼因子μ：
(JᵀJ + μI)·Δx = -Jᵀf

μ的作用：
- μ大时：H + μI ≈ μI，退化为梯度下降（安全但慢）
- μ小时：H + μI ≈ H，近似高斯-牛顿（快但可能不稳）
- 当Hessian近似不好时自动增大μ保证正定性

**A5.11**
LM更新公式：
Δx = -(JᵀJ + μI)⁻¹·Jᵀf

μ的调节策略（Marquardt策略）：
- 计算增益比 ρ = (实际下降)/(近似下降)
- ρ大（近似好）→ 减小μ（更信任二次近似，更接近高斯-牛顿）
- ρ小（近似差）→ 增大μ（更保守，接近梯度下降）

**A5.12**
阻尼因子μ动态调整：
1. 初始化μ（如μ = τ·max(aᵢᵢ)）
2. 求解 (JᵀJ + μI)Δx = -Jᵀf
3. 计算增益比 ρ
4. 如果ρ > 阈值（如0.75）：接受更新，减小μ（如μ ← μ/3）
5. 如果ρ < 阈值（如0.25）：拒绝更新，增大μ（如μ ← μ×2）
6. 回到步骤2

**A5.13**
Ceres基本步骤：
1. 定义代价函数（CostFunction）：继承SizedCostFunction或使用AutoDiffCostFunction
2. 定义参数块（ParameterBlock）：待优化变量
3. 添加残差块：problem.AddResidualBlock(cost_function, loss_function, parameter_blocks)
4. 设置求解器选项（SolverOptions）：迭代次数、求解器类型等
5. 求解：Solve(options, &problem, &summary)

LossFunction用于降低外点影响（如HuberLoss）。

**A5.14**
g2o框架：
- **顶点（Vertex）**：待优化的变量，对应SLAM中的相机位姿、路标点
- **边（Edge）**：连接顶点的约束，对应观测（重投影误差）或先验（里程计约束）

**A5.15**
g2o优化流程：
1. 定义顶点类型（位姿VertexSE3、路标VertexSBAPointXYZ）
2. 添加顶点并设置初始值
3. 定义边类型（重投影误差边EdgeProjectXYZ2UV）
4. 添加边，连接对应的顶点，设置观测值和信息矩阵
5. 设置优化参数（迭代次数、算法类型LM/GN）
6. 调用optimize()执行优化

**A5.16**
鲁棒核函数：将大残差的增长从二次降为线性或更低，减小外点对优化的影响。

必要性：SLAM中存在错误匹配（外点），其残差极大。如果直接用二次核，外点会主导整个目标函数，使优化偏离正确解。

Huber核函数：
ρ(e) = { ½e²          if |e| ≤ δ
        { δ|e| - ½δ²   if |e| > δ

小残差时等价于二次核，大残差时退化为线性增长。

# 第六讲 视觉里程计1：特征点法

**A6.1**
特征点是图像中具有独特性、可重复检测的点。好的特征点应具备：
- **可重复性**：在不同图像中能检测到同一个点
- **独特性**：与周围区域有明显区别
- **高效性**：检测和匹配速度快
- **不变性**：对旋转、尺度、光照有一定不变性

**A6.2**
FAST角点检测原理：
1. 选取像素p，考虑其周围半径为3的圆上的16个像素
2. 如果圆上有连续N个（通常N=12）像素的亮度都高于或低于p的亮度一个阈值，则p为角点
3. 快速测试：先检查1,5,9,13四个位置的像素，至少3个满足才继续

**A6.3**
ORB特征优势：
- 速度极快（比SIFT快两个数量级）
- 免费开源（SIFT申请了专利）
- 具有旋转不变性（通过计算角点方向实现）

旋转不变性实现（oFAST）：在FAST角点的邻域内计算图像矩，得到角点的主方向，以此方向为参考计算BRIEF描述子。

**A6.4**
BRIEF描述子：在角点周围随机选取256个点对，比较每对点的灰度大小，生成256位二进制串。

steered BRIEF改进：根据角点的主方向旋转采样点对的位置，使描述子具有旋转不变性。同时通过学习方法筛选区分度高的点对。

**A6.5**
SIFT步骤：
1. 尺度空间极值检测（DoG金字塔）
2. 关键点定位（亚像素精化）
3. 方向分配（基于梯度直方图）
4. 描述子生成（128维浮点向量）

尺度不变性：通过高斯金字塔检测不同尺度的特征。
旋转不变性：通过主方向分配，描述子相对主方向计算。

**A6.6**
暴力匹配：对第一幅图像中的每个特征描述子，与第二幅图像中所有描述子计算距离（汉明距离/欧氏距离），取距离最小的作为匹配。

**A6.7**
比率测试（Lowe's ratio test）：
对每个特征，计算最近邻距离d₁和次近邻距离d₂。如果 d₁/d₂ < threshold（通常0.6-0.8），才接受该匹配。

作用：过滤掉描述子不够独特的匹配（容易混淆的特征），降低错误匹配率。

**A6.8**
FLANN（Fast Library for Approximate Nearest Neighbors）使用索引结构（如KD-Tree、层级聚类树）加速最近邻搜索，适合大规模特征匹配。

优势：在特征数量大时（>几千个），比暴力匹配快很多。
适用场景：大规模特征匹配、实时SLAM系统。

**A6.9**
对极约束推导：
设P为三维空间点，O₁和O₂为两个相机光心，p₁和p₂为P在两个图像上的投影。

- **极平面**：由O₁、O₂、P三点确定的平面
- **极线**：极平面与像平面的交线（l₁和l₂）
- **极点**：基线O₁O₂与像平面的交点（e₁和e₂）

对极约束：p₂ᵀ·F·p₁ = 0（用基础矩阵表示）
或：p₂_cᵀ·E·p₁_c = 0（用本质矩阵表示，p_c为归一化坐标）

**A6.10**
本质矩阵E定义：E = t^·R（或 E = [t]_×·R），描述了两视图之间的对极几何关系。

自由度：5个自由度（3个旋转 + 3个平移 - 1个尺度等价性 = 5）。

平移t有尺度不确定性（E乘以任意非零常数不影响对极约束），所以只有5个自由度。

**A6.11**
- E（本质矩阵）：联系归一化图像坐标，只与相机外参（R,t）有关
- F（基础矩阵）：联系像素坐标，与内参和外参都有关
- 关系：F = K⁻ᵀ·E·K⁻¹，或 E = Kᵀ·F·K

**A6.12**
八点法步骤：
1. 对每对匹配点 (p₁, p₂)，写出对极约束 p₂ᵀEp₁ = 0
2. 将E的9个元素拉成向量e，每对点提供一个线性方程
3. 8对点构成 8×9 的方程组 Ae = 0
4. 对A做SVD分解，e取V的最后一列（最小奇异值对应的向量）
5. 将e重塑为3×3矩阵E
6. 对E做SVD并在SVD空间中投影到本质矩阵空间（S = diag(σ₁,σ₂,0)修正）
7. 从E分解出R,t

**A6.13**
从E分解R,t的方法：
E = U·diag(σ₁,σ₂,0)·Vᵀ（SVD分解后强制秩为2）

可能得到4个解：
R₁ = U·W·Vᵀ, R₂ = U·Wᵀ·Vᵀ, t₁ = U₃, t₂ = -U₃
（W = ⎡0 -1 0; 1 0 0; 0 0 1⎤）

共2×2=4种组合。选择标准：将P投影到两个相机中，取P在两个相机前方（深度Z>0）的那个解。

**A6.14**
单应矩阵H适用于场景近似平面（如墙面、地面）或相机纯旋转的情况。本质矩阵E适用于一般3D场景的相机平移+旋转。

当场景退化为平面时，E的估计不稳定，H更鲁棒。实际系统中通常同时估计E和H，根据重投影误差选择更好的结果。

**A6.15**
H有8个自由度（3×3矩阵，9个元素，除以一个非零因子后剩8个）。

DLT算法：
1. 对每对匹配点 (p₁, p₂)，写出 p₂ × (H·p₁) = 0，得到2个线性方程
2. 4对点提供8个方程，构成 Ah = 0（h为H展平后的向量）
3. 对A做SVD，取V的最后一列
4. 重塑为3×3矩阵H

**A6.16**
三角测量原理：
已知两帧的位姿(R₁,t₁)和(R₂,t₂)，以及匹配点p₁和p₂。

s₁p₁ = s₂(Rp₂ + t)，其中s₁和s₂为深度。

这是关于s₁、s₂的线性方程，用最小二乘法求解，得到P的三维坐标。

**A6.17**
影响因素：
1. **平移量（基线）**：平移越大，三角化越准确。平移太小时视差不够，深度估计不准（类似人眼看远处物体难以判断距离）
2. **特征点位置精度**：像素坐标的误差会放大到深度估计
3. **观测角度**：与基线方向平行的特征点三角化更准确

**A6.18**
三角测量线性解法：
对每帧 i，有 sᵢ·pᵢ = P_cᵢ = Rᵢ·P_w + tᵢ

叉积消去 sᵢ：pᵢ × (Rᵢ·P_w + tᵢ) = 0

每帧提供2个方程，N帧提供2N个方程，求解3个未知数（P_w的xyz）。

用SVD求最小二乘解。但线性解法忽略了噪声的统计特性，所以常在之后用BA进行非线性优化精化。

**A6.19**
PnP问题：已知n个3D点在世界坐标系中的坐标和它们在图像上的2D投影，估计相机的位姿(R,t)。

在SLAM中，当前帧已经有一些已知3D路标点（由前面的帧三角化得到），通过匹配当前帧的2D特征点与这些3D路标，用PnP估计当前帧的位姿。

**A6.20**
P3P算法：
1. 已知3个3D点A,B,C和它们在图像上的投影a,b,c
2. 利用余弦定理建立关于3D点到相机中心距离的比例关系
3. 消元得到关于3个距离的二次方程，最多4个解
4. 用第4个点验证选择正确的解
5. 得到3个3D点在相机坐标系下的坐标
6. 用ICP（3D-3D匹配）求解R,t

**A6.21**
EPnP基本思想：
1. 选择4个控制点（通常为3D点的质心和三个主方向上的点）
2. 将每个3D点表示为控制点的加权和：Pᵢ = Σ αᵢⱼ·Cⱼ
3. 利用投影关系建立关于控制点在相机坐标系下坐标的线性方程
4. 求解方程得到控制点的相机坐标
5. 通过3D-3D对应关系恢复R,t

EPnP复杂度为O(n)，比P3P更稳定。

**A6.22**
BA形式的PnP：
目标函数：min Σ ||uᵢ - π(T·Pᵢ)||²

其中：
- uᵢ为观测到的2D像素坐标
- π(T·Pᵢ)为3D点Pᵢ投影到当前帧的预测像素坐标
- T为待优化的相机位姿

仅优化位姿T（3D点固定），使用高斯-牛顿或LM求解。

**A6.23**
ICP问题：给定两组3D点云（一组来自上一帧的3D路标，一组来自当前帧三角化后的3D点），求解它们之间的刚体变换(R,t)。

场景：双目或RGB-D相机可以直接获得3D点，不需要三角化。

**A6.24**
SVD方法求解ICP：
1. 计算两组点云的质心：p̄ = Σpᵢ/n, p̄' = Σp'ᵢ/n
2. 去质心：qᵢ = pᵢ - p̄, q'ᵢ = p'ᵢ - p̄'
3. 计算W = Σ q'ᵢ·qᵢᵀ
4. SVD分解W = UΣVᵀ
5. R = U·Vᵀ（如果det(R)=-1则R = U·diag(1,1,-1)·Vᵀ）
6. t = p̄' - R·p̄

**A6.25**
ICP的非线性优化形式：
目标：min Σ ||p'ᵢ - (R·pᵢ + t)||²

用李代数φ表示旋转：
1. 误差 eᵢ = p'ᵢ - exp(φ^)·pᵢ - t
2. 计算eᵢ对φ和t的雅可比
3. 构建正规方程 H·Δx = g
4. 迭代更新 φ和t

相比SVD方法，非线性优化可以方便地加入鲁棒核函数和约束。

# 第七讲 视觉里程计2：直接法

**A7.1**
根本区别：直接法不需要显式提取和匹配特征点，直接利用**像素灰度**信息，通过最小化**光度误差**来估计相机运动。

直接法利用的信息：图像的灰度值和梯度信息。

**A7.2**
光度误差定义：同一三维点在两帧图像中的灰度差。
eᵢ = I₁(pᵢ) - I₂(π(T₂·π⁻¹(pᵢ, dᵢ)))

目标函数：min_T Σ ||eᵢ||²

其中I₁、I₂为两帧图像的灰度，pᵢ为像素坐标，dᵢ为深度，T₂为待估计的位姿。

**A7.3**
光度误差对位姿的雅可比推导：
e = I₁(p) - I₂(u)

∂e/∂δξ = -∂I₂/∂u · ∂u/∂P_c · ∂P_c/∂δξ

其中：
- ∂I₂/∂u = [∂I/∂x, ∂I/∂y]（图像梯度，2维）
- ∂u/∂P_c = K·∂(P_c/Z)/∂P_c（投影对3D点的导数）
- ∂P_c/∂δξ = [I, -P_c^]（SE(3)扰动模型的导数）

综合后：∂e/∂δξ = -∇I₂·K·[I, -P_c^]/Z

**A7.4**
灰度不变性假设：同一空间点在不同图像中的灰度值相同。

不成立的情况：
- 光照变化（环境光改变）
- 高光/反射（镜面反射区域灰度变化剧烈）
- 曝光变化
- 自动增益/白平衡调整

直接法在这些情况下会失效或精度下降。

**A7.5**
| 类型 | 利用的像素 | 精度 | 效率 |
|------|-----------|------|------|
| 稀疏直接法 | 少量梯度明显的像素 | 较低（信息少） | 最快 |
| 半稠密直接法 | 所有梯度明显的像素 | 中等 | 中等 |
| 稠密直接法 | 所有像素 | 高（信息最多） | 最慢 |

LSD-SLAM使用半稠密，DSO使用稀疏直接法。

**A7.6**
LSD-SLAM属于**半稠密直接法**，利用图像中梯度较大的像素。
主要贡献：
1. 首次实现实时大规模直接法视觉里程计
2. 构建半稠密的深度图
3. 提出基于Sim(3)的位姿图优化（处理尺度漂移）
4. 回环检测也基于直接法的光度误差

**A7.7**
光流描述了像素在相邻帧之间的运动。LK光流法的基本假设：
1. 灰度不变性：I(x+dx, y+dy, t+dt) = I(x, y, t)
2. 小运动：相邻帧之间像素位移很小
3. 空间一致性：邻域内像素运动相同

**A7.8**
LK光流推导：
灰度不变性Taylor展开：I(x+dx,y+dy) - I(x,y) ≈ ∂I/∂x·dx + ∂I/∂y·dy = 0

即 ⎡Ix  Iy⎤·⎡dx; dy⎤ = 0

假设邻域W×W内运动相同，得到W²个方程：
A·⎡dx; dy⎤ = b

最小二乘解：⎡dx; dy⎤ = -(AᵀA)⁻¹·Aᵀb

需要图像梯度不平行（即Ix和Iy方向都有变化），否则AᵀA不可逆。这就是角点区域适合做光流的原因。

**A7.9**
金字塔光流在多尺度上计算：
1. 先在低分辨率（粗层）计算大位移的近似
2. 将结果传递到高分辨率（细层）进行精化
3. 逐层精化，最终得到亚像素精度

作用：解决LK光流的小运动假设——大位移可以通过粗层分解为多个小位移。

**A7.10**
联系：光流可以看作直接法在2D-2D情况下的特例——先通过光流跟踪得到像素对应关系，再用这些对应关系估计运动。直接法则将光流计算和运动估计统一到一个优化框架中。

**A7.11**
图像梯度离散近似（前向差分）：
∂I/∂x ≈ I(x+1,y) - I(x,y)
∂I/∂y ≈ I(x,y+1) - I(x,y)

或中心差分：
∂I/∂x ≈ [I(x+1,y) - I(x-1,y)] / 2
∂I/∂y ≈ [I(x,y+1) - I(x,y-1)] / 2

**A7.12**
逆深度参数化：用 d_inv = 1/d 代替深度 d 作为参数。

优势：
1. 单目SLAM中深度范围从0到∞，用逆深度后范围变为0到有限值
2. 逆深度的分布更接近高斯分布（实验观察），适合用高斯滤波器更新
3. 可以统一表示无穷远点（d_inv = 0）
4. 深度不确定度较大时，逆深度的方差更稳定

**A7.13**
| 方面 | 特征点法 | 直接法 |
|------|----------|--------|
| 鲁棒性 | 高（特征对光照/视角变化较鲁棒） | 低（依赖灰度不变性） |
| 精度 | 在稀疏点上精度高 | 可利用更多信息，稠密区域精度高 |
| 速度 | 特征提取和匹配耗时 | 计算简单但需要求解大规模方程 |
| 适用场景 | 纹理丰富、光照变化大的场景 | 纹理较少、连续变化的场景 |

**A7.14**
DSO改进：
1. **稀疏化**：只选梯度明显的点（而非半稠密），提高效率
2. **光度标定**：显式建模曝光时间、晕影效应、响应函数，提高光度一致性
3. **窗口优化**：在滑动窗口内联合优化多个关键帧和点
4. **点选择策略**：均匀分布在图像中，避免聚集
5. 整体精度比LSD-SLAM有显著提升

# 第八讲 后端1

**A8.1**
Bundle Adjustment（光束法平差）：
- **Bundle**：指从路标点发出到相机光心的"光束"
- **Adjustment**：调整这些光束，使重投影误差最小

BA同时优化相机位姿和路标点位置，是最精确的SLAM后端方法。

**A8.2**
BA代价函数：
min_{T,M} Σᵢ Σⱼ ||eᵢⱼ||² = min Σᵢ Σⱼ ||uᵢⱼ - π(Tᵢ·Mⱼ)||²_Σ

- Tᵢ：第i个相机位姿（SE(3)）
- Mⱼ：第j个路标点（ℝ³）
- uᵢⱼ：第i帧对第j个路标的观测像素坐标
- π(·)：投影函数
- eᵢⱼ：重投影误差

**A8.3**
BA的Hessian矩阵 H = JᵀJ 的结构：

H = ⎡H_cc  H_cl⎤  其中：
    ⎣H_lc  H_ll⎦

- H_cc：相机-相机块（位姿对位姿），大小与相机数量有关
- H_ll：路标-路标块（路标对路标），大小与路标数量有关
- H_cl, H_lc：相机-路标交叉块

稀疏性来源：每个观测只关联一个相机和一个路标，没有"相机-相机"或"路标-路标"的直接观测。H_cl块非常稀疏（大部分相机和路标没有观测关系）。

**A8.4**
舒尔补：利用H的分块结构消去路标部分。

⎡H_cc  H_cl⎤⎡Δx_c⎤ = ⎡g_c⎤
⎣H_lc  H_ll⎦⎣Δx_l⎦   ⎣g_l⎦

消去Δx_l：Δx_l = H_ll⁻¹(g_l - H_lc·Δx_c)

代入第一行：(H_cc - H_cl·H_ll⁻¹·H_lc)·Δx_c = g_c - H_cl·H_ll⁻¹·g_l

左侧 S = H_cc - H_cl·H_ll⁻¹·H_lc 就是舒尔补。

关键：H_ll是对角块矩阵（路标之间独立），H_ll⁻¹计算高效。消元后只需解一个关于相机位姿的较小线性系统。

**A8.5**
BA求解过程：
1. 构建Hessian H = JᵀJ 和梯度 g = -Jᵀe
2. 对H进行分块：⎡B  E; Eᵀ  C⎤，其中B=H_cc, E=H_cl, C=H_ll
3. 计算舒尔补 S = B - E·C⁻¹·Eᵀ
4. 求解 S·Δx_c = g_c - E·C⁻¹·g_l（位姿增量）
5. 回代 Δx_l = C⁻¹(g_l - Eᵀ·Δx_c)（路标增量）
6. 更新位姿和路标，迭代

步骤4是主要计算瓶颈，S的大小只与相机数量有关。

**A8.6**
外点的重投影误差通常非常大（几十甚至上百像素），在二次代价函数中贡献极大，会使优化结果被外点"拉偏"，导致内点的优化也被破坏。

**A8.7**
Huber核函数：
ρ(e) = { ½e²          if |e| ≤ δ
        { δ|e| - ½δ²   if |e| > δ

- 残差小时（|e| ≤ δ）：等价于二次核，正常优化
- 残差大时（|e| > δ）：线性增长，大幅降低外点的影响

**A8.8**
柯西核函数：ρ(e) = λ²·log(1 + e²/λ²)

相比Huber核，柯西核对大残差的增长更加缓慢（对数级别），对外点的抑制更强。选择取决于场景中预期的外点比例。

**A8.9**
位姿图：只保留相机位姿作为节点，不包含路标点。边表示两个位姿之间的相对运动约束（来自里程计或回环检测）。

引入原因：
1. BA中路标点数量远多于相机数量，消去路标后仍计算量大
2. 长时间运行后，路标点数量爆炸
3. 位姿图只优化轨迹，规模小得多
4. 可作为全局优化后的"快速修正"

**A8.10**
位姿图代价函数：
min Σₖ ||eₖ||²_Σₖ

其中 eₖ = log(Tₖⱼ⁻¹·Tᵢⱼ·ΔTᵢⱼ⁻¹)^  （李代数空间的误差）

- Tᵢ, Tⱼ：第i个和第j个位姿
- ΔTᵢⱼ：观测到的相对运动
- eₖ表示"从位姿图估计的相对运动"与"观测到的相对运动"之间的差异

**A8.11**
相对运动误差（李代数形式）：
设第i个位姿为Tᵢ = exp(ξᵢ^)，第j个为Tⱼ = exp(ξⱼ^)

相对运动：Tⱼ·Tᵢ⁻¹ = exp(ξⱼ^)·exp(-ξᵢ^)

观测相对运动：ΔTᵢⱼ = exp(Δξᵢⱼ^)

误差：e = log(ΔTᵢⱼ⁻¹·Tⱼ·Tᵢ⁻¹)^ ≈ ξⱼ - ξᵢ - Δξᵢⱼ（一阶近似）

**A8.12**
位姿图中：
- 顶点：相机位姿（SE(3)或其李代数）
- 边：相对运动约束（连接两个位姿）
- 信息矩阵：通常为单位矩阵或根据观测不确定性设置（如里程计误差小则信息矩阵大）

**A8.13**
因子图是更一般的框架。位姿图可看作因子图的特例——只包含位姿变量和相对运动因子。因子图可以包含任意类型的因子（先验、里程计、观测、回环等），更灵活。

**A8.14**
贝叶斯网络 → 因子图对应：
- 先验因子：对初始位姿的约束
- 里程计因子：相邻位姿之间的运动约束（对应运动方程）
- 观测因子：位姿对路标的观测约束（对应观测方程）

因子图中的每个因子对应一个概率分布项。

**A8.15**
iSAM（增量式平滑与建图）：
- 只对新加入的变量和受影响的变量进行增量更新
- 利用Bayes树数据结构，维护变量之间的依赖关系
- 当新数据到来时，只更新Bayes树的相关部分
- 避免了每次都做全局BA的巨大计算量

iSAM2进一步改进，使用完全增量式的Bayes树更新。

# 第九讲 后端2

**A9.1**
EKF-SLAM流程：

**预测步骤**：
- 状态预测：x̂ₖ = f(x̂ₖ₋₁, uₖ)
- 协方差预测：P̂ₖ = FₖPₖ₋₁Fₖᵀ + Qₖ

**更新步骤**：
- 计算卡尔曼增益：Kₖ = P̂ₖHₖᵀ(HₖP̂ₖHₖᵀ + Rₖ)⁻¹
- 状态更新：xₖ = x̂ₖ + Kₖ(zₖ - h(x̂ₖ))
- 协方差更新：Pₖ = (I - KₖHₖ)P̂ₖ

**A9.2**
EKF-SLAM状态向量：x = [位姿, m₁, m₂, ..., mₙ]ᵀ（3+3n维）

协方差矩阵维度：(3+3n) × (3+3n)

随着路标点n的增长，协方差矩阵呈二次增长，计算复杂度为O(n²)，限制了可处理的地图规模。

**A9.3**
| EKF | 图优化 |
|-----|--------|
| 优点：实时性好，增量更新 | 优点：可回溯修正，精度高 |
| 缺点：线性化误差累积，规模受限 | 缺点：全局优化计算量大 |
| 适合：小规模、资源受限 | 适合：大规模、精度要求高 |

**A9.4**
EKF对非线性函数做一阶泰勒展开：
f(x) ≈ f(x₀) + ∂f/∂x|_{x₀}·(x - x₀)

线性化误差来源：
1. 只保留一阶项，忽略高阶项
2. 每步更新的线性化点不同，累积误差
3. 非线性程度高时（大旋转、大位移），一阶近似不准确
4. 可能导致协方差估计过于乐观（实际误差比估计的大）

**A9.5**
本质区别：
- EKF：维护当前状态的**均值和协方差**，每次只用最新观测更新（马尔可夫假设）
- BA：维护**所有历史状态**，可以用新信息回溯修正旧状态

EKF是"增量式"的（信息只用一次），BA是"批量式"的（信息可以反复使用）。

**A9.6**
滑动窗口：只保留最近N帧和对应路标进行优化，丢弃更早的变量。

平衡：
- 窗口大：精度高但计算量大
- 窗口小：计算量小但可能丢失有用信息

实际中通常选择窗口大小为5-15帧。

**A9.7**
边缘化目的：从窗口中移除旧变量时，保留其对剩余变量的约束信息（不直接丢弃）。

舒尔补应用：
将Hessian ⎡H_mm  H_mr; H_rm  H_rr⎤ 中边缘化变量m部分消去：
H̃_rr = H_rr - H_rm·H_mm⁻¹·H_mr

H̃_rr保留了被移除变量的信息，作为先验约束加入后续优化。

**A9.8**
FEJ原理：在进行边缘化后，后续优化中与边缘化相关的雅可比矩阵应**固定在边缘化时的线性化点**计算。

原因：如果每次迭代重新计算雅可比（线性化点变了），会导致信息不一致——边缘化时的先验信息与新优化的线性化不匹配，可能使系统过于自信甚至发散。

**A9.9**
典型SLAM前后端协作：
1. **前端**：实时处理每帧图像，估计帧间运动，生成初始位姿和地图点
2. **后端**：接收前端的关键帧和地图点，在后台线程执行优化
3. **局部优化**：每当插入新关键帧，优化附近的位姿和路标
4. **全局优化**：检测到回环时，触发全局BA或位姿图优化

**A9.10**
| 框架 | 特点 | 适用场景 |
|------|------|----------|
| Ceres | 自动求导，接口简单 | 通用非线性优化，快速原型 |
| g2o | 图优化框架，支持多种边和顶点 | 视觉SLAM后端 |
| GTSAM | 因子图，支持增量式优化(iSAM2) | VIO、多传感器融合 |

**A9.11**
iSAM2优势：
1. 增量式更新，不需要每次做完整的线性化
2. 利用Bayes树结构，只更新受影响的变量
3. 支持变量重线性化和批量步骤的灵活调度
4. 适合实时、长时间运行的SLAM系统

# 第十讲 回环检测

**A10.1**
回环检测：判断机器人是否回到了之前经过的位置。

必要性：
1. 消除累积漂移：提供跨时间的约束，连接过去和当前的位姿
2. 保证全局一致性：使地图"闭合"，避免断裂和重影
3. 是SLAM区别于纯里程计的关键

**A10.2**
- 回环检测：检测机器人是否回到了之前的位置
- 重定位：在丢失追踪后，利用已有地图恢复位姿

联系：两者都需要在当前帧和历史帧之间建立匹配。回环检测是时间跨度的匹配，重定位是利用地图的匹配。

**A10.3**
没有回环检测：
- 轨迹的累积漂移无法修正
- 闭环路径的终点和起点不重合
- 地图出现断裂或重影（同一位置出现两个不同的地图表示）

**A10.4**
词袋模型基本思想：
1. **描述子（Descriptor）**：图像特征点的数值表示
2. **单词（Word）**：将描述子空间聚类，每一类为一个单词
3. **字典（Vocabulary）**：所有单词的集合（通常用树状结构组织）
4. 每幅图像可以表示为单词的直方图（词袋向量），用于快速比较相似度

**A10.5**
字典构建流程：
1. 从大量图像中提取特征描述子
2. 用K-means对描述子进行聚类（如K=10）
3. 对每个聚类中心递归地继续K-means，形成树状结构（深度通常为3-6层）
4. 叶子节点即为字典中的"单词"

树状结构优势：
- 查找速度快（O(logN)而非O(N)）
- 层级结构提供了从粗到细的匹配
- 字典体积更小

**A10.6**
TF-IDF用于衡量单词的"区分度"：
- TF（词频）：单词在该图像中出现的频率
- IDF（逆文档频率）：log(总图像数/包含该单词的图像数)，越常见的单词IDF越低

TF-IDF权重：w = TF × IDF

作用：让"罕见但具区分度"的特征权重高，"常见但不具区分度"的特征权重低。

**A10.7**
两幅图像的相似度计算：
1. 将两幅图像表示为词袋向量 v₁ 和 v₂
2. 计算L1距离：s = 2 - 2·Σ|v₁ᵢ - v₂ᵢ|（或L2距离等其他度量）
3. 值越大表示越相似

**A10.8**
DBoW3使用流程：
1. 加载字典：`Vocabulary vocab; vocab.load("vocab.yml.gz");`
2. 创建数据库：`Database db(vocab, false, 0);`
3. 将图像加入数据库：`db.add(feature_descriptors);`
4. 查询：`QueryResults results; db.query(query_descriptors, results, max_results);`
5. 根据得分排序，取最相似的候选帧

**A10.9**
单帧匹配不可靠的原因：
1. 相似场景（如走廊、办公室）可能导致误匹配
2. 单帧得分受噪声影响

连续性检测：只有连续多帧（如3帧以上）都检测到与某个历史帧的高相似度，才认为是真正的回环。这降低了误检率。

**A10.10**
精确率 = 正确回环数 / (正确回环数 + 错误回环数)
召回率 = 正确回环数 / (实际回环数)

在SLAM中应优先保证**精确率**：一个错误的回环比漏检一个回环更危险（错误回环会严重破坏地图）。

**A10.11**
错误匹配类型：
1. 场景相似但位置不同（如两个相似的走廊）
2. 动态物体导致的假匹配

几何验证方法：
1. 用候选回环帧的特征点与当前帧进行特征匹配
2. 计算本质矩阵/基础矩阵并用RANSAC剔除外点
3. 内点数量超过阈值才接受回环

**A10.12**
深度学习在回环检测中的应用：
- **NetVLAD**：用CNN提取全局图像描述子，可学习VLAD聚合
- **VLAD + CNN**：将局部特征用CNN提取后聚合
- **端到端方法**：直接输入图像输出相似度分数
- 优势：可以学习更鲁棒的特征表示，对视角和光照变化更鲁棒

**A10.13**
VLAD（Vector of Locally Aggregated Descriptors）：
1. 对每个局部描述子，找到最近的聚类中心
2. 计算描述子与聚类中心的残差
3. 将所有残差按聚类中心聚合

相比BoW：VLAD保留了描述子与聚类中心的残差信息（BoW只记录计数），因此更精确。

# 第十一讲 建图

**A11.1**
建图目的：为导航、避障、交互等下游任务提供环境的空间信息。

不同应用对地图的要求：
- **导航/避障**：需要稠密地图（知道哪些区域可通行）
- **定位**：稀疏地图即可（特征点足够定位）
- **重建/可视化**：需要稠密/半稠密地图
- **语义理解**：需要语义标签

**A11.2**
| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 稀疏地图 | 只含特征点（路标），占用空间小 | 定位 |
| 半稠密地图 | 包含梯度明显的像素区域 | 导航、基本避障 |
| 稠密地图 | 所有像素都有深度信息 | 三维重建、导航、避障 |

**A11.3**
| 表示形式 | 优点 | 缺点 |
|----------|------|------|
| 路标点 | 紧凑，定位用 | 信息稀疏 |
| 点云 | 直观，易于生成 | 无拓扑信息，数据量大 |
| 网格（Mesh） | 有拓扑，可视化好 | 生成复杂 |
| 八叉树 | 支持概率更新，高效查询 | 精度受分辨率限制 |
| 栅格地图 | 导航友好 | 仅2D，内存占用大 |

**A11.4**
单目稠密重建流程：
1. 选取关键帧
2. 对每个像素（或部分像素），在其他关键帧中搜索对应点（极线搜索）
3. 利用多视角观测估计深度
4. 深度滤波器融合多次观测
5. 生成稠密深度图，转换为点云或网格

单目需要多视角：单张图像无法恢复深度，需要不同视角的观测形成视差。

**A11.5**
极线搜索稠密深度估计：
1. 在参考帧I_ref中选取像素p_ref
2. 根据当前深度估计d，计算p_ref对应的3D点P
3. 将P投影到另一帧I_2中，得到p_2
4. 由于深度d不确定，p_2沿极线滑动
5. 沿极线搜索，找到使灰度差最小的位置
6. 该位置对应的深度即为估计深度

**A11.6**
深度滤波器（高斯分布假设）：
- 深度假设 d ~ N(μ, σ²)
- 每次新观测更新深度分布

更新步骤：
1. 在极线上搜索最佳匹配，得到新的深度观测d_obs
2. 计算观测不确定性 σ_obs（与极线搜索的不确定性有关）
3. 贝叶斯更新：
   - σ²_new = σ²·σ_obs² / (σ² + σ_obs²)
   - μ_new = (σ_obs²·μ + σ²·d_obs) / (σ² + σ_obs²)
4. 当σ足够小时，认为深度收敛

**A11.7**
逆深度参数化优势：
1. 深度范围 [0, +∞) 映射到逆深度 (0, +∞)，更紧凑
2. 可以表示无穷远点（逆深度=0）
3. 逆深度的分布更接近高斯，适合高斯滤波
4. 远处点深度方差大时，逆深度方差相对稳定

**A11.8**
- NCC（归一化互相关）：衡量两个图像块的相似度，值域[-1,1]，值越大越相似。对光照变化有一定鲁棒性。
- SSD（误差平方和）：两个图像块灰度差的平方和，值越小越相似。

在极线搜索中，用这些度量在极线上找到最佳匹配位置。

**A11.9**
点云是三维空间中大量离散点的集合，每个点有(x,y,z)坐标和可选的颜色信息。

RGB-D点云：每帧深度图直接转换为3D点，质量高、噪声低。
双目点云：需要通过视差计算深度，匹配误差会影响点云质量。

**A11.10**
点云拼接流程：
1. 获取每帧的深度图和相机位姿（由SLAM前端/后端提供）
2. 将每帧深度图的每个像素反投影为3D点（使用相机内参）
3. 将3D点从相机坐标系变换到世界坐标系：P_w = T_wc·P_c
4. 将所有帧的点云融合到统一的世界坐标系

**A11.11**
滤波作用：
- **体素滤波**：将空间划分为体素网格，每个体素只保留一个点（质心），均匀降采样
- **统计滤波**：对每个点计算其邻域的平均距离，移除离群点（平均距离过大的点）
- 目的：去除噪声点、减少数据量、提高后续处理效率

**A11.12**
八叉树数据结构：
1. 将三维空间递归地划分为8个子立方体
2. 每个节点存储该区域的占据概率
3. 当子区域的分辨率满足要求时停止细分
4. 空闲区域和占据区域分别用不同状态标记

优势：自适应分辨率——细节区域细分，平坦区域粗表示。

**A11.13**
八叉树概率更新：
log-odds更新：L(n) = L(n-1) + L_update

其中 L = log(P(occupied) / P(free))

- 被观测到"占据"：L_update > 0
- 被观测到"空闲"（射线穿过）：L_update < 0
- 未观测：L_update = 0

三种状态：
- P(occ) > 阈值 → 被占据（障碍物）
- P(free) > 阈值 → 空闲（可通行）
- 其他 → 未确定

**A11.14**
八叉树地图优势：
1. 概率表示可以融合多次观测，处理噪声
2. 支持动态更新（标记空闲区域用于路径规划）
3. 自适应分辨率，内存效率高
4. 导航中可以快速查询某位置是否可通行
5. 压缩存储（空闲的子树可以剪枝）

# 第十二讲 双目稠密重建

**A12.1**
- 单目稠密重建：通过极线搜索+深度滤波间接估计深度，存在尺度不确定性
- 双目稠密重建：已知基线和内参，通过视差直接计算深度，尺度确定

**A12.2**
流程：
1. **图像校正**：将左右图像变换到共面行对齐（使极线水平）
2. **立体匹配**：对左图每个像素，在右图的对应极线上搜索最佳匹配
3. **视差计算**：计算匹配位置的视差 d = u_left - u_right
4. **深度转换**：depth = f·B / d
5. **后处理**：左右一致性检验、空洞填充、滤波

**A12.3**
校正目的：使左右图像的极线完全水平对齐（共面且行对齐），将二维搜索降为一维搜索。

Bouguet算法：
1. 计算左右相机的旋转矩阵R和平移t
2. 将旋转平均分配给两个相机（各旋转R_half = R^(1/2)）
3. 调整投影矩阵使两图像平面共面
4. 输出校正后的图像和新的投影矩阵

**A12.4**
视差 d = u_left - u_right（像素单位）
深度 z = f·B / d

其中：
- f：焦距（像素单位）
- B：基线（米）
- d：视差（像素）

深度误差 Δz ≈ z²·Δd / (f·B)，远处物体深度误差大。

**A12.5**
SGM核心思想：在多个方向上进行一维路径聚合，近似全局能量函数的最小化。

改进：
- 局部匹配只考虑当前像素或小窗口
- SGM通过多路径聚合，利用了半全局信息
- 代价聚合时加入平滑约束（惩罚视差跳变）
- 比局部匹配更鲁棒，比全局方法（如图割）更快

**A12.6**
Census变换：将每个像素的灰度与其邻域像素比较，生成二进制编码。

优势：
- 对光照变化鲁棒（只比较相对大小，不依赖绝对灰度）
- 计算简单高效
- 适合硬件实现

直接比较灰度对光照变化和曝光差异敏感。

**A12.7**
- **左右一致性检验**：分别计算左→右和右→左的视差图，如果某点在两个方向的视差不一致，标记为无效。检测遮挡和错误匹配。
- **空洞填充**：对无效区域用周围有效视差插值填充，生成完整的视差图。

**A12.8**
多帧深度图融合：
1. 对每帧深度图，根据相机位姿变换到世界坐标系
2. 用TSDF或点云融合方法，将多帧深度信息融合
3. 需要的信息：深度图 + 相机内参 + 每帧位姿

**A12.9**
TSDF（Truncated Signed Distance Function）：
- 在三维网格中存储每个体素到最近表面的带符号距离
- SDF > 0：在表面前方（空闲）；SDF < 0：在表面后方（被占据）；SDF = 0：在表面上
- 截断（Truncated）：只保留表面附近的值，远处设为±1

融合过程：
1. 对每个体素，投影到每帧深度图
2. 计算该体素到表面的距离
3. 加权平均更新TSDF值
4. 提取零等值面（Marching Cubes）得到网格

**A12.10**
KinectFusion流程：
1. **深度图预处理**：双边滤波去噪
2. **ICP配准**：将当前帧与全局模型对齐，估计相机位姿
3. **TSDF融合**：将当前帧深度融合到全局TSDF体素
4. **光线投射（Ray Casting）**：从TSDF中渲染虚拟深度图用于下一帧ICP

GPU加速：TSDF融合和光线投射高度并行，适合GPU实现，达到实时帧率。

# 第十三讲 项目实践

**A13.1**
完整SLAM系统模块：
1. **传感器数据获取**：读取图像/IMU数据
2. **前端（追踪）**：特征提取/匹配、运动估计、关键帧选取
3. **局部地图管理**：局部BA、地图点筛选
4. **后端（优化）**：全局BA/位姿图优化
5. **回环检测**：词袋匹配、几何验证
6. **建图**：地图表示和输出
7. **可视化**：实时显示轨迹和地图

协同：前端实时运行，后端和回环在后台线程运行。

**A13.2**
数据交换机制：
- **线程安全队列**：前端将关键帧推入队列，后端从队列取出处理
- **互斥锁（Mutex）**：保护共享数据（如地图）的并发访问
- **条件变量**：线程间通知（如"新的关键帧可用"）
- 关键原则：最小化锁的持有时间，避免死锁

**A13.3**
关键帧的作用：减少冗余数据，保留有信息量的帧用于优化。

选取策略：
1. 距离上一个关键帧超过阈值（平移或旋转）
2. 追踪到的特征点数量低于阈值（视角变化大）
3. 追踪质量下降（内点比例低）
4. 不宜过于频繁（增加后端负担）或过于稀疏（信息丢失）

**A13.4**
地图点管理策略：
- **创建**：三角化生成新地图点，要求足够的视差
- **保留条件**：在至少N（如3）个关键帧中被观测到
- **剔除**：连续多帧未被观测到、质量评分过低、深度为负
- 目的：保持地图质量，减少冗余计算

**A13.5**
单目初始化需要特殊的处理，因为单目无法从单帧获取深度。

初始化过程：
1. 检测初始两帧之间的特征匹配
2. 计算基础矩阵F或单应矩阵H（根据场景选择）
3. 分解得到R,t（注意尺度不确定，通常设t的模长为1）
4. 三角化初始地图点
5. 执行初始BA精化

如果初始化失败（特征匹配不足、纯旋转等），需要等待更多帧重新尝试。

**A13.6**
追踪丢失判断：
- 匹配的特征点数量低于阈值
- 重投影内点比例过低
- 优化后的误差过大

处理策略：
1. 增大搜索范围重新匹配
2. 利用IMU数据预测位姿（如果有）
3. 利用词袋进行重定位
4. 如果持续丢失，宣告系统丢失并尝试重新初始化

**A13.7**
恒速运动模型：假设相机运动速度恒定（匀速），用上一帧到当前帧的运动预测下一帧的位姿。

T_predict = T_current · T_current · T_prev⁻¹

利用预测位姿可以将特征点投影到当前帧的预期位置附近，缩小搜索范围，加速匹配并提高鲁棒性。

**A13.8**
| 类型 | 优化范围 | 触发时机 |
|------|----------|----------|
| 局部BA | 当前帧附近的N个关键帧及其观测到的地图点 | 每插入新关键帧后 |
| 全局BA | 所有关键帧和地图点 | 回环检测后，或系统结束时 |

局部BA保持实时性，全局BA在后台运行保证全局一致性。

**A13.9**
规模增长处理：
1. **滑动窗口**：只保留最近N个关键帧，旧的关键帧被边缘化
2. **位姿图**：消去路标点，只优化位姿（规模小得多）
3. **子地图**：将地图分为多个子地图，子地图内部优化，子地图间用位姿图连接
4. **关键帧淘汰**：删除冗余的关键帧

**A13.10**
回环校正流程：
1. 回环检测确认回环
2. 计算当前帧与回环帧之间的Sim(3)变换（含尺度）
3. 将回环约束加入位姿图
4. 执行位姿图优化（调整所有关键帧位姿）
5. 根据优化后的位姿调整地图点位置
6. 合并重复的地图点
7. 可选：执行全局BA进一步精化

**A13.11**
常用数据集：
- KITTI（自动驾驶）、EuRoC（无人机）、TUM RGB-D（室内）、KITTI Odometry

评价指标：
- ATE（绝对轨迹误差）
- RPE（相对位姿误差）

**A13.12**
- **ATE（绝对轨迹误差）**：将估计轨迹与真值轨迹对齐（SE(3)或Sim(3)对齐）后，计算每个时刻的位姿误差。衡量全局一致性。
  ATE = RMSE(||T_gt,i⁻¹·T_est,i||)

- **RPE（相对位姿误差）**：计算固定时间间隔内位姿变化的误差。衡量漂移率。
  RPE(Δt) = RMSE(||(T_gt,i⁻¹·T_gt,i+Δt)⁻¹·(T_est,i⁻¹·T_est,i+Δt)||)

**A13.13**
evo工具使用：
1. 安装：`pip install evo`
2. 对齐计算ATE：`evo_ape kitti gt.txt est.txt -va --align --correct_scale`
3. 计算RPE：`evo_rpe kitti gt.txt est.txt -va --delta 1 --delta_unit m`
4. 可视化：`evo_traj kitti gt.txt est.txt -va --plot_mode xyz`

# 第十四讲 展望

**A14.1**
主要挑战：
1. **光照变化**：白天/夜晚、室内外切换
2. **动态环境**：行人、车辆等动态物体干扰
3. **缺乏纹理**：白墙、玻璃等弱纹理区域
4. **大规模场景**：长时间运行的内存和计算限制
5. **快速运动**：运动模糊导致追踪丢失
6. **传感器退化**：遮挡、过曝光等

**A14.2**
语义SLAM在几何SLAM基础上增加了语义理解：
- 识别物体类别（桌子、椅子、门）
- 利用语义约束优化位姿和地图
- 区分动态和静态物体
- 生成语义地图（不仅知道"那里有东西"，还知道"那是门"）

提升：
- 动态物体剔除（提高鲁棒性）
- 语义约束辅助定位
- 面向任务的导航（"去厨房"而非"去坐标(x,y)"）

**A14.3**
深度学习在SLAM中的应用：
- **前端特征提取**：SuperPoint、R2D2等学习型特征
- **深度估计**：单目深度估计网络（如MiDaS）
- **回环检测**：NetVLAD等全局描述子
- **语义分割**：识别物体和区域
- **光流估计**：RAFT等学习型光流
- **端到端SLAM**：尝试从数据直接学习SLAM

**A14.4**
多传感器融合优势：
- 互补性：视觉提供丰富纹理信息，IMU提供高频运动信息
- 鲁棒性：单一传感器退化时其他传感器可补偿
- 可观性：IMU提供重力方向，解决单目的尺度问题

VIO基本原理：将视觉观测和IMU测量在统一框架中联合优化，视觉约束全局位置，IMU约束帧间运动。

**A14.5**
IMU提供：
- **角速度**（陀螺仪）：三轴旋转速度
- **线加速度**（加速度计）：包含重力加速度

补充作用：
1. 提供高频（200-1000Hz）的运动估计，弥补视觉帧率低（30Hz）的不足
2. 提供重力方向约束
3. 在视觉短暂丢失时维持运动估计
4. 提供尺度参考（单目+IMU可恢复真实尺度）

**A14.6**
IMU预积分：
- 问题：IMU测量频率远高于视觉帧率，两帧之间有大量IMU测量
- 直接积分：每当位姿更新，所有IMU积分需要重新计算，代价大
- 预积分思想：将IMU积分表示为**相对于前一帧**的增量，独立于全局位姿
- 当位姿更新时，预积分量不需要重新计算
- 预积分量 ΔR, Δv, Δp 可直接在两帧之间使用

**A14.7**
| 类型 | 方式 | 优点 | 缺点 |
|------|------|------|------|
| 松耦合 | 视觉和IMU各自估计，融合结果 | 实现简单，模块化 | 信息损失 |
| 紧耦合 | 视觉和IMU原始数据联合优化 | 精度高，充分利用信息 | 实现复杂 |

紧耦合是主流方法（VINS-Mono, OKVIS等）。

**A14.8**
经典VIO系统：
- **VINS-Mono**：单目+IMU紧耦合，滑动窗口优化，支持回环检测
- **OKVIS**：多传感器紧耦合，关键帧BA
- **MSCKF**：基于EKF的多状态约束卡尔曼滤波，效率高
- **ROVIO**：直接法VIO，不需要特征提取

**A14.9**
| 特性 | 视觉SLAM | Lidar SLAM |
|------|----------|------------|
| 传感器 | 相机（便宜、轻便） | 激光雷达（贵、重） |
| 信息丰富度 | 高（颜色、纹理） | 低（几何点云） |
| 几何精度 | 中等 | 高（厘米级） |
| 适用环境 | 纹理丰富 | 结构丰富（走廊、建筑） |
| 受光照影响 | 大 | 小 |

**A14.10**
基于NeRF/Gaussian Splatting的SLAM：
- 传统方法：显式表示地图（点云/网格/体素），分别优化位姿和地图
- NeRF SLAM：用隐式神经辐射场表示场景，联合优化相机位姿和场景表示
- 3DGS SLAM：用3D高斯椭球体表示场景，可实时渲染

本质区别：将场景表示和位姿估计统一到一个可微渲染框架中，通过比较渲染图像和真实图像来优化。

**A14.11**
实时性与精度平衡：
- 降低优化频率（如仅对关键帧优化）
- 滑动窗口限制计算规模
- 多线程（前端实时，后端后台运行）
- GPU加速稠密计算

嵌入式挑战：
- 算力有限（CPU/GPU性能弱）
- 内存有限
- 功耗限制
- 通常需要算法轻量化或专用硬件加速

**A14.12**
这是一个开放性问题，主流观点：
- 短期内，传统几何方法在可靠性和效率上仍有优势
- 深度学习在特定模块（特征提取、深度估计、回环检测）已经超越传统方法
- 端到端学习方法在泛化性和可解释性上仍有不足
- 未来趋势是**混合方法**：用深度学习增强传统SLAM的各个模块
- 纯端到端方法可能在特定场景（如自动驾驶）逐步成熟，但通用SLAM仍需几何约束
